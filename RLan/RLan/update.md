# 功能升级

## UI

- 将侧边栏修改为功能标签切换
`
标签：
1. 加入/创建房间
2. 房间列表（房间管理）
3. 聊天（新功能）
4. 设置
`
- 新增功能聊天，文字消息直接显示，其他文件仅作传输（图片有预览功能），将房间详情内的消息广播功能代替。
- 房间详情中应该显示该房间是否可达公网等的详细信息
- 保存房间信息，软件重启后房主端应自动重启房间，房客端自动加入。（该功能暂不启用，仅编写相关代码）
- 可以在设置中配置上述功能的一些详细信息
## 安全

直接将ip作为房间号的一部分并不安全。将ip和端口等隐私信息和房间密码进行对称加密。
修改密码将重启房间并生成新的房间id。
已经加入房间的成员在房间密码被修改时应该自动加入新的房间
